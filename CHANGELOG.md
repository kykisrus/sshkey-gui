# История изменений

## 0.6.2 — 2026-11-23

- Новая иконка приложения: PNG 512×512 с прозрачными углами для Linux и
  мультиразмерная `.ico` для Windows (`packaging/icon.ico`).
- Иконка используется в меню, на ярлыке рабочего стола, в `.deb` и в `sshkey-gui.exe`.

## 0.6.1 — 2026-11-23

- Сборка установочных пакетов: `.deb` для Linux (`packaging/build-deb.sh`) и
  `sshkey-gui.exe` для Windows (PyInstaller).
- GitHub Actions: по тегу собирает оба пакета и публикует релиз с вложениями.
- Кроссплатформенность: поиск `ssh`/`ssh-keygen` через `PATH`, работа через браузер
  там, где нет GTK (Windows и минимальные Linux), сервер при этом не завершается.

## 0.6.0 — 2026-11-23

- Новый интерфейс с боковым меню: «SSH-ключи», «Подключение» (раздел-заглушка,
  помечен «скоро»), «Настройки».
- Кнопка «Создать ключ…» над списком: имя, тип (`ed25519`, `rsa` 4096, `ecdsa`),
  комментарий и необязательная парольная фраза. Проверка имени и защита от перезаписи.
- Настройки: дополнительные каталоги с ключами (абсолютные пути, проверка существования)
  и выгрузка ключей в архив `.tar.gz` — публичные всегда, приватные только по флагу.
- Ключи из нескольких каталогов помечаются своим путём; настройки хранятся в
  `~/.config/sshkey-gui/settings.json`.
- Переменные окружения `SSHKEY_GUI_SSH_DIR` и `SSHKEY_GUI_CONFIG_DIR` для нестандартных
  раскладок и тестов.
- В README добавлено изображение и разделы про новые возможности.

## 0.5.2 — 2026-11-23

Первый публичный выпуск.

- Список SSH-ключей с отпечатками и типом; ключи без приватной пары недоступны для передачи.
- Проверка связи: TCP, время отклика, SSH-баннер и проверка входа выбранным ключом.
- Передача публичного ключа через `authorized_keys` без `ssh-copy-id`:
  корректные права (`700`/`600`), защита от дубликатов, экранирование строки ключа.
- Автоматическая проверка входа по ключу после передачи.
- Окно приложения на GTK3 + WebKit2, пункт меню, иконка и ярлык на рабочем столе;
  фолбэк на браузер, если GTK/WebKit недоступны.
- Интерфейс обезличен: поля пустые, подсказки нейтральные, значения не сохраняются.
- Раскладка на всё окно: панели растягиваются по высоте, прокрутка — только внутри
  списка ключей, страница не прокручивается.
- Одноразовый askpass для передачи с паролем; пароль не пишется в файлы и логи.
- Защита локального HTTP-интерфейса: только `127.0.0.1` и проверка заголовка `Host`
  (против DNS-rebinding).
- Скрипты установки и удаления для текущего пользователя.
