# История изменений

## 0.5.2 — 2026-11-23

Первый публичный выпуск.

- Список SSH-ключей с отпечатками и типом; ключи без приватной пары недоступны для передачи.
- Проверка связи: TCP, время отклика, SSH-баннер и проверка входа выбранным ключом.
- Передача публичного ключа через `authorized_keys` без `ssh-copy-id`:
  корректные права (`700`/`600`), защита от дубликатов, экранирование строки ключа.
- Автоматическая проверка входа по ключу после передачи.
- Окно приложения на GTK3 + WebKit2, пункт меню, иконка и ярлык на рабочем столе;
  фолбэк на браузер, если GTK/WebKit недоступны.
- Интерфейс обезличен: поля пустые, подсказки нейтральные, значения не сохраняются.
- Раскладка на всё окно: панели растягиваются по высоте, прокрутка — только внутри
  списка ключей, страница не прокручивается.
- Одноразовый askpass для передачи с паролем; пароль не пишется в файлы и логи.
- Защита локального HTTP-интерфейса: только `127.0.0.1` и проверка заголовка `Host`
  (против DNS-rebinding).
- Скрипты установки и удаления для текущего пользователя.
